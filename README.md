# Timed Typing Test App

## Project Description

This project is a professional timed typing test application built with HTML, CSS, and JavaScript. The app measures how quickly and accurately a user can type a randomly selected paragraph.

The project demonstrates JavaScript objects, functions, event handling, DOM manipulation, timers, and data persistence using Local Storage.

## Features

- Minute, second, and hundredths timer
- Real-time typing validation
- Dynamic border color feedback
  - Grey: ready state
  - Blue: typing correctly
  - Red: typo detected
  - Green: test completed
- Random typing prompt selection
- Words Per Minute calculation
- Error counter
- Start Over button
- Top 3 fastest scores saved with Local Storage
- Responsive and polished user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
